# Junion

##  Описание проекта
Junion — это веб-приложение для молодых дизайнеров, которое помогает находить стажировки, получать первый опыт работы и развивать профессиональные навыки.

Платформа соединяет начинающих специалистов и компании, заинтересованные в стажёрах.

---

## Цели проекта
- Упростить поиск стажировок для начинающих дизайнеров  
- Дать возможность получить первый опыт работы  
- Создать удобную платформу для взаимодействия дизайнеров и компаний  

---

## Целевая аудитория
- студенты дизайнерских направлений  
- начинающие UI/UX дизайнеры  
- компании и стартапы  

---

## Основной функционал

### Для пользователей:
- регистрация и авторизация  
- создание профиля  
- просмотр стажировок  
- отклик на вакансии  

## Для компаний:
- размещение стажировок  
- просмотр откликов  
- выбор кандидатов  

---

##  Используемые технологии
- Frontend: HTML, CSS, JavaScript  
- Backend: Node.js  
- База данных: MongoDB  
- Облачные технологии: AWS  

---

---

##  Архитектура системы

Приложение построено по клиент-серверной архитектуре:

- Клиент (Frontend) — пользовательский интерфейс  
- Сервер (Backend) — обработка запросов  
- База данных — хранение информации  

---

##  Сценарий работы пользователя
1. Пользователь регистрируется в системе  
2. Создает профиль  
3. Просматривает список стажировок  
4. Откликается на интересующие предложения
