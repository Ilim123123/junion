# Junion

Junion — это платформа для молодых дизайнеров, которая помогает находить стажировки и получать опыт работы.

##  Цель
Помочь начинающим дизайнерам получить первый опыт работы.

##  Технологии
JavaScript
Node.js
MongoDB
AWS

##  Архитектура
Клиент-серверное приложение:
клиент (интерфейс)
сервер (логика)
база данных

#  Использование
1. Регистрация
2. Создание профиля
3. Поиск стажировок
4. Отклик

#  AWS
Проект использует AWS для хостинга и хранения данных.
